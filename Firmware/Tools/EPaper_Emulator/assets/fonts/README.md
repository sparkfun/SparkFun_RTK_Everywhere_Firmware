# Candidate fonts for the 184x88 big HPA / SIV digits

Source fonts for `bigtext_fonts.py` (rendered to 1-bit glyphs, exported to the firmware by
`export_bigdigits.py`). All licenses allow embedding the rendered glyphs in firmware.

| File | Font | License |
| --- | --- | --- |
| DejaVuSansMono-Bold.ttf, DejaVuSansCondensed-Bold.ttf | DejaVu | Bitstream Vera / DejaVu (permissive) |
| CascadiaMono.ttf | Cascadia Mono (variable, Bold instance used) | SIL OFL 1.1 |
| IBMPlexMono-Bold.ttf | IBM Plex Mono | SIL OFL 1.1 |
| ter-u*b.bdf | Terminus Font 4.49.1, bold | SIL OFL 1.1 (Terminus-OFL.txt) |
| spleen-*.bdf | Spleen 2.1.0 | BSD 2-Clause (Spleen-LICENSE.txt) |
